Strategic Employee Attrition Intelligence Dashboard

📌 About the Project

This project analyzes employee attrition using SQL and Power BI. It helps identify employee turnover patterns and provides useful workforce insights.

🛠️ Tools Used

- SQL – Data analysis and validation
- Power BI – Data cleaning, KPI creation, visualization, and dashboard

📊 Key Results

- Total Employees: 5,000
- Employees Left: 895
- Attrition Rate: 17.9%

📈 Dashboard

The dashboard provides analysis based on:

- Department
- Job Role
- Work Mode
- Income
- Overtime
- Employee Wellbeing
- AI Tool Adoption

🎯 Objective

To convert employee data into simple and interactive insights that help understand employee attrition patterns
